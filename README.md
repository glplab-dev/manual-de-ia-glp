# Manual de IA — Comercial GLP Laboratórios

Manual interno vivo sobre como usar IA no dia a dia do comercial — tool-agnostic (vale para ChatGPT, Claude, Gemini ou qualquer outra ferramenta), cobrindo desde os primeiros passos até prompting, exemplos práticos por área, segurança, ética, FAQ e glossário.

## Como usar

O manual é uma única página HTML autocontida (`index.html`) — sem dependências externas de build, sem servidor. Basta abrir o arquivo no navegador.

## Publicar com GitHub Pages

Depois de subir este repositório no GitHub:

1. Vá em **Settings → Pages**
2. Em "Source", selecione a branch `main` e a pasta `/ (root)`
3. Salve — o GitHub gera uma URL pública (algo como `https://<seu-usuário>.github.io/<nome-do-repo>/`) em alguns minutos

Isso dá um link público, sem depender de conta no Claude, que você pode compartilhar com o time e atualizar sempre que editar o `index.html`.
